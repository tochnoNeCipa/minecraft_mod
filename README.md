# RoboHelper 1.4.0

Minecraft Java 1.20.1 / Fabric Loader 0.16.14+ / Fabric API 0.92.2+1.20.1.

Скачайте robohelper-1.4.0.jar и поместите в mods вместе с Fabric API, заменив предыдущий JAR RoboHelper.

Добавлены фермер и логист: сбор и пересадка пшеницы, моркови, картофеля и свёклы; выгрузка в сундуки и бочки внутри рабочей зоны с сохранением запаса семян. Лесоруб продолжает работу после освобождения хранилища.

Выдача предметов: /give @s robohelper:robot_body, /give @s robohelper:farmer_module, /give @s robohelper:logistics_module.
Откройте робота, установите модули, положите топливо и семена, задайте зону и включите WORK. Для логиста поставьте сундук или бочку в зоне; автоматическая выгрузка начинается при заполнении 13 из 18 слотов или остановке производства из-за переполнения.

Исходный коммит: 03f0d2ff0f472bef45a6446129b5f0a62937c8d4
Фермер: 124f3ef; логист: 03f0d2f.
Проверка: сборка успешна, 78/78 серверных GameTests. Графическая проверка версии 1.4.0 вручную не проводилась.
