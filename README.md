# RoboHelper 1.1.0

Исходный коммит: f79fd4e655ce8acb8a8b9c81be2f5936033832ae

Minecraft Java 1.20.1, Fabric Loader >=0.16.14, Fabric API 0.92.2+1.20.1.
Проверки: сборка, 34/34 серверных GameTest, просмотр русского GUI в клиенте.
Добавлен GUI владельца: слоты, энергия, режимы, перенос центра и ручная выгрузка.
Профессии пока не реализованы; кнопка направления недоступна без шахтёра.
Замените прежний RoboHelper JAR файлом robohelper-1.1.0.jar в папке mods. Fabric API также обязателен.
ПКМ пустой рукой открывает экран; Shift+ПКМ выгружает хранение, оставляя топливо и модули.
Скриншот получен из настоящего Minecraft с тестовыми данными, без игрового мира; функциональные действия отдельно проверены серверными тестами.
