# RoboHelper 1.6.1: комплект для защиты

Скачайте robohelper-1.6.1-defense.zip, распакуйте ZIP целиком и откройте «00_НАЧНИ_ЗДЕСЬ.html».

01_МОД — проверенный JAR RoboHelper 1.6.1.
02_ИСХОДНИКИ — чистый проект Gradle/Fabric для IntelliJ IDEA.
03_ОТЧЁТЫ — Word/HTML-отчёт, исходные JSON/XML, графики и скриншоты.
04_ИНСТРУКЦИИ — Word/HTML-инструкция: запуск, карта клиентской/серверной части кода и сценарий демонстрации.

Нужны отдельно установленные Minecraft Java 1.20.1, Fabric Loader и Fabric API. Для сборки исходников — JDK 17 и интернет при первой загрузке зависимостей.

Результаты 113 тестов и сетевой приёмки относятся к 16.11.2026; при упаковке они заново не запускались. JAR совпадает с проверенным выпуском по SHA-256. Пояснительная записка, презентация, игровой мир и видео готовятся отдельно.
