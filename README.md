# RoboHelper 1.2.0

Исходный коммит: ae4f14a83847b746626a2282760684792910597d

Minecraft Java 1.20.1 / Fabric Loader >=0.16.14 / Fabric API 0.92.2+1.20.1.
Два этапа: каркас профессий 6606a93 и рабочий лесоруб ae4f14a.
Сборка и 51/51 серверный GameTest прошли, включая повторный чистый запуск.
Ручная графическая сессия нового лесоруба пока не проверена.

Замените старый JAR в mods файлом robohelper-1.2.0.jar. Fabric API также должен быть установлен.
Создайте робота рядом с естественным деревом, установите модуль Лесоруб ПКМ или через GUI, положите уголь и саженцы, выберите WORK.
Команда получения модуля: /give @s robohelper:lumberjack_module
Рецепт: железный топор + 2 редстоуна + 2 железных слитка, бесформенный.
Рубка идёт сверху вниз, брёвна попадают в хранение, после рубки саженец пересаживается. При переполнении робот останавливается до освобождения места.
Уровни повышаются после 100 и 500 действий, прогресс сохраняется в предмете.
Фермер, логист, шахтёр и охранник ещё не реализованы.
