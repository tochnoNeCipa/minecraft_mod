# RoboHelper 1.6.1

Minecraft Java 1.20.1 / Fabric Loader 0.16.14+ / Fabric API 0.92.2+1.20.1.

Скачайте robohelper-1.6.1.jar, замените предыдущий JAR RoboHelper в mods и перезапустите игру/сервер. Fabric API также должен быть установлен. Существующих роботов пересоздавать не нужно.

Все пять профессий: лесоруб, фермер, шахтёр, охранник и логист. Три слота модулей на робота.

Версия 1.6.1 закрывает доступную приёмку:
- 113/113 обязательных серверных тестов.
- Два настоящих Fabric-клиента: права владельца, GUI, слоты, кнопки и сообщение шахтёра.
- Полный перезапуск выделенного сервера с сохранением недокопанного тоннеля; настоящая выгрузка и повторная загрузка чанка.
- Замеры баланса (дуб, тоннель, поле 9×9), нагрузки на 1/3/5/10 роботах; исходные JSON/XML, графики и скриншоты RU/EN.

Архив robohelper-1.6.1-validation.zip содержит документацию и результаты. Порог средней нагрузки ТЗ выполнен в контролируемых сценариях; методика и максимумы приведены в отчёте.

Серверная сессия автоматизирована на localhost в offline-mode; Microsoft-вход не проверялся. OpenAL не открыл аудиоустройство, слышимость звуков надо проверить на обычном ПК. Длительное публичное бета-тестирование и совместимость с другими модами остаются следующим шагом.
