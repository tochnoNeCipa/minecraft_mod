# RoboHelper 1.6.0

Minecraft Java 1.20.1 / Fabric Loader 0.16.14+ / Fabric API 0.92.2+1.20.1.

Скачайте robohelper-1.6.0.jar и замените предыдущий JAR RoboHelper в папке mods. Fabric API тоже должен быть установлен. Перезапустите игру/сервер. Существующих роботов пересоздавать не нужно.

Все пять профессий реализованы: лесоруб, фермер, шахтёр, охранник и логист. Одновременно у робота три слота модулей.

Добавлено:
- Шахтёр: тоннель 1×2 до границы зоны; защита контейнеров, блоков-сущностей и чёрного списка; остановка перед жидкостями и глубоким обрывом; сохранение задания при перезапуске и выгрузке.
- Охранник: враждебные мобы в радиусе 10 блоков внутри зоны, ближний бой и возврат к центру; приоритет над другими профессиями; таймаут недоступной цели.

Выдача:
/give @s robohelper:miner_module
/give @s robohelper:guard_module

Крафт: железная кирка (шахтёр) или железный меч (охранник) + 2 редстоуна + 2 железных слитка. Установите модуль, добавьте топливо и включите WORK. Кнопка «Направление» начинает новый тоннель по направлению взгляда робота.
