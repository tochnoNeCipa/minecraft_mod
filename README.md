# RoboHelper 1.4.1

Minecraft Java 1.20.1 / Fabric Loader 0.16.14+ / Fabric API 0.92.2+1.20.1.

Скачайте robohelper-1.4.1.jar и замените предыдущий JAR RoboHelper в папке mods.

Исправлено: робот проходит по грядкам к центральным посевам сплошного поля и может собирать и пересаживать, стоя на грядке. Защита от вытаптывания сохранена.
Существующего робота пересоздавать не нужно. После замены JAR перезапустите игру/сервер.

Исходный коммит: 3a99e6bcbf978ce0eba3d8b8183da1c5ca83f4f4
Сборка успешна, 79/79 обязательных серверных GameTests прошли без ошибок и пропусков. Проверены центральный урожай на поле 11×11, работа с грядки и сохранность почвы и неспелых растений. Ручная графическая проверка этой версии не проводилась.
