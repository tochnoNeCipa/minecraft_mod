# RoboHelper: комплект для защиты

Версия мода: **1.6.1**. Назначение комплекта: запуск мода, просмотр исходников,
демонстрация архитектуры и предъявление результатов проверки.

## Что открыть сначала

1. Распакуй ZIP целиком в отдельную папку. На Windows: ПКМ → «Извлечь всё».
2. Открой `00_НАЧНИ_ЗДЕСЬ.html` в браузере: это оглавление комплекта.
3. Для запуска возьми JAR из `01_МОД`.
4. Для объяснения кода открой проект из `02_ИСХОДНИКИ/проект` в IntelliJ IDEA.
5. Для результатов открой `03_ОТЧЁТЫ/Результаты_проверок.docx`.
6. В `04_ИНСТРУКЦИИ` находится Word-файл с запуском, картой кода и сценарием показа.

Исходный проект сохранён в структуре Gradle/Fabric: `src/client`, `src/main`,
`src/gametest`, `src/release`. Папки внутри проекта не нужно переименовывать
во «фронтенд» и «бэкенд»: они указаны в настройках сборки.

## Что подготовить на компьютере заранее

- Minecraft **Java Edition 1.20.1**.
- Fabric Loader **0.16.14 или новее, совместимый с 1.20.1**.
- Fabric API **0.92.2+1.20.1**: [официальная страница](https://modrinth.com/mod/fabric-api).
- Для сборки исходников — **JDK 17**. Для открытия Word-файлов — Word или совместимый редактор.
- Minecraft, Fabric Loader, Fabric API и JDK устанавливаются отдельно.

Положи `robohelper-1.6.1.jar` и JAR Fabric API в папку `mods` выбранного профиля.
Удали из этой папки предыдущую версию RoboHelper, чтобы остался один JAR мода.
Запусти игру через профиль Fabric 1.20.1. На выделенном сервере мод и Fabric API
должны стоять также на сервере и у подключающихся игроков.

До защиты запусти игру и загрузи демонстрационный мир хотя бы один раз.
Первая установка и первая сборка Gradle требуют интернета; подготовь их дома.
Игровые сохранения для демонстрации создаются отдельно от этого комплекта.

## Быстрый запуск демонстрации

Создай творческий мир с разрешёнными командами. Выдай себе предметы:

```mcfunction
/give @s robohelper:robot_body
/give @s robohelper:lumberjack_module
/give @s robohelper:farmer_module
/give @s robohelper:miner_module
/give @s robohelper:guard_module
/give @s robohelper:logistics_module
/give @s minecraft:coal 16
/give @s minecraft:oak_sapling 16
/give @s minecraft:wheat_seeds 64
```

1. Используй корпус по верхней стороне блока; над ним должно быть достаточно места.
2. Открой робота ПКМ пустой рукой. Новый робот находится в IDLE.
3. Вставь нужные модули: одновременно доступны **три слота**, а профессий всего пять.
4. Положи уголь в топливный слот. Семена и саженцы — в обычное хранение.
5. Задай центр кнопкой «Зона здесь». Радиус зоны — 15 блоков по горизонтали и ±8 по вертикали.
6. Кнопкой режима включи WORK. Для остановки выбери IDLE, для следования — FOLLOW.

Для модуля максимального, третьего уровня:

```mcfunction
/give @s robohelper:farmer_module{"RoboHelper.Counter":500} 1
```

Имя `farmer_module` можно заменить на имя другой профессии.

## Как открыть и собрать исходники

Открой `02_ИСХОДНИКИ/проект` как проект Gradle, выбери Gradle JVM = JDK 17.
Отдельно установленный Gradle не требуется: Wrapper включён в комплект.

Windows, командная строка в папке проекта:

```bat
gradlew.bat build
gradlew.bat runGametest --no-daemon
```

Linux/macOS:

```bash
./gradlew build
./gradlew runGametest --no-daemon
```

После сборки игровой файл находится в `build/libs/robohelper-1.6.1.jar`.
JAR с окончанием `-sources` содержит исходники и не используется как игровой мод.
GameTests создают собственный мир в `build/gametest/world` и удаляют только этот
проверочный мир перед повторным запуском. Команда проверки не открывает игровое окно.

## Если что-то не запускается

- Игра сообщает об отсутствующей зависимости: проверь Fabric API и версию профиля.
- Мод не появился: проверь, что JAR находится в `mods` именно запущенного профиля.
- Робот стоит: проверь WORK, энергию выше 320, модуль и цель внутри зоны.
- Лесоруб не трогает дерево: вырасти дерево из саженца; брёвна без естественной листвы он игнорирует.
- Шахтёр остановлен: проверь жидкость, контейнер, чёрный список и обрыв. Кнопка
  «Направление» начинает новый тоннель по направлению взгляда робота.
- Логист не выгружает: обычно нужен порог 13 занятых слотов из 18 либо переполнение
  производства, доступный сундук/бочка внутри зоны и место в контейнере.
- Ошибка сборки Java: проверь JDK 17 и доступ к загрузке зависимостей при первом запуске.

## Что подтверждено отчётами

Материалы проверок относятся к запуску **16.11.2026**, а не к новому тестированию
при упаковке комплекта. В отчётах: **113/113** серверных тестов, два настоящих
Fabric-клиента, перезапуск отдельного серверного процесса, выгрузка чанков,
проверка баланса и нагрузки. Нагрузка измерялась в описанных контролируемых сценариях.

OpenAL не открыл аудиоустройство в облачной среде: слышимость звука требуется
проверить на обычном ПК. Длительное публичное прохождение и совместимость
с произвольными наборами модов этими результатами не подтверждаются.
